# Legal archive

Reference artifacts kept in the repository for defensive purposes only.
Files in this directory are **not** served by the Astro site (only `public/`
is published) and are not linked from any page.

## Contents

- `vailent-product-page-archive-YYYY-MM-DD.pdf` — point-in-time capture of
  Vailent's public Catalog / Material Management product page
  (https://www.vailent.com/solutions/material-management). Archived to
  document what Vailent had publicly published as of the capture date, in
  case any portion of the public page is later updated or removed.
